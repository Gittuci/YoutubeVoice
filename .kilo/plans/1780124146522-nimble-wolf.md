## Step 7: NEW `pipeline/fcpxml.py` — FCPXML Generator

### Inputs:
- Original video path (Phase 2 downloaded video or kept copy)
- Per-language SRT file (`master_{lang}.srt`)
- Per-language WAV segment list (from Phase 4 output)
- Language code

### Output:
- `output/fcpxml_{lang}.fcpxml` — DaVinci Resolve compatible FCPXML

### FCPXML Structure:
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE fcpxml>
<fcpxml version="1.12">
  <resources>
    <format id="r1" name="FFVideoFormat..." frameDuration="..." width="..." height="..."/>
    <asset id="r2" name="original_video" src="file:///absolute/path/to/video.mp4" 
           start="0s" duration="..." hasAudio="1" audioChannels="2" audioRate="48000"/>
    <!-- One asset per WAV segment -->
    <asset id="r3_wav_1" name="de_seg_0001" src="file:///absolute/path/to/de_seg_0001.wav"
           start="0s" duration="..." hasAudio="1" audioChannels="1" audioRate="24000"/>
    ...
  </resources>
  <library location="file:///...">
    <event name="Foltvilag_{LANG}">
      <project name="Voiceover_{LANG}">
        <sequence format="r1" duration="...">
          <spine>
            <!-- Video Track 1: original video, muted -->
            <asset-clip ref="r2" offset="0s" name="original_video" 
                        start="0s" duration="..."
                        audioRole="dialogue" audioStart="0s" audioDuration="...">
              <adjust-volume amount="-inf"/>
            </asset-clip>
            <!-- Audio Track 1: time-stretched WAV chunks at exact SRT timestamps -->
            <gap name="Gap" offset="0s" duration="{start_time}s" start="0s">
              <asset-clip ref="r3_wav_1" offset="{start_time}s" 
                          name="de_seg_0001" start="0s" duration="{wav_duration}s"/>
            </gap>
            ...
          </spine>
        </sequence>
      </project>
    </event>
  </library>
</fcpxml>
```

### Implementation Details:

1. **`build_fcpxml(video_path, srt_path, lang, wav_segments, output_path)`** — main function
   - Parse SRT to get timestamps and durations
   - Read WAV file durations (from file headers, not ffprobe)
   - Generate resource IDs and asset definitions
   - Build spine with video clip + gapped audio clips
   - Write .fcpxml file

2. **Helper: `_get_video_info(video_path)`** — extract video dimensions, frame rate, duration via ffprobe
3. **Helper: `_get_wav_duration(wav_path)`** — read WAV header for duration
4. **Helper: `_format_fcpxml_time(seconds)`** — format seconds as "1234/24000s" style

### CLI:
```
python -m pipeline.fcpxml --lang de --srt output/master_de.srt --wav-dir output/wav_segments --video temp/video.mp4 --output output/fcpxml_de.fcpxml
```
