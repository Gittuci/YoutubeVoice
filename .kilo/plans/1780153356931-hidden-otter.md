## Plan: Set up isolated Python virtual environment

### Problem

All `pip install` commands have been running against the system Python (`C:\Users\user\AppData\Local\Programs\Python\Python312\python.exe`), installing packages globally. This can cause version conflicts across projects.

### Steps

1. **Create `.venv`** — `python -m venv .venv` in project root
2. **Add `.venv/` to `.gitignore`** — prevent committing the venv
3. **Install dependencies into venv** — `.\.venv\Scripts\python.exe -m pip install -r requirements.txt`
4. **Verify** — `.\.venv\Scripts\python.exe -c "import google.genai; import openai; print('OK')"`

### Notes

- The existing `.gitignore` already covers `.env`, `output/`, `temp/`, `__pycache__/`, and media artifacts — only `.venv/` needs adding.
- `requirements.txt` has no version pins — future follow-up could add `pyproject.toml` with locked versions, but that's out of scope for this fix.
- No other files change.
