## 8. Externalize Expression Tags

**Source:** `voice.py:166-176` — `_build_tagged_text()`:
```python
tagged = entry_text
if is_first:
    tagged = f"[enthusiasm] {tagged}"
return tagged
```

**Target:** `prompts/expression_tags.txt`
```
[enthusiasm]
```
(Single tag; could be expanded later with multiple tags per position)

**Code change in `voice.py`:** Load the tag from file at module level, use it in `_build_tagged_text`:
```python
def _build_tagged_text(entry_text: str, is_first: bool) -> str:
    tag = config.load_prompt("expression_tags.txt")
    if is_first:
        return f"{tag} {entry_text}"
    return entry_text
```
